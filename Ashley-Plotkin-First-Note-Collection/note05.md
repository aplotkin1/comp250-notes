Vim 05 - Understanding Zotero

# Title

Zotero Helps Manage Research Sources

# Quotation

“Zotero is a completely free, open-source reference manager.”

# Citation

Bradburn, Steven. “How To Use Zotero (A Complete Beginner’s
Guide).” YouTube video, 12:40. October 13, 2021.
https://www.youtube.com/watch?v=JG7Uq_JFDzE.

# Point Locator

00:14

# Commentary

This quote explains the basic purpose of Zotero and why it
can be useful for students. A reference manager gives
students a place to keep track of the sources they find while
researching. This can be especially useful when an assignment
requires several different sources and citations. Using a
tool like Zotero can make research more organized while still
leaving the actual reading and thinking to the student.

# Keywords

Zotero, references, research, organization
