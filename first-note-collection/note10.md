# Commentary

Branching is useful because it allows changes to be made
without immediately changing the main version of a project.
A programmer can work on a feature in a separate branch and
later combine it with the main branch. This seems especially
helpful when multiple people are working on the same project.
It allows people to experiment with changes while keeping
the main project organized.
