Vim 06 - Organizing Zotero Sources

# Title

Collections Keep Research Organized

# Quotation

“Collections are basically folders where you can add specific
references into.”

# Citation

Bradburn, Steven. “How To Use Zotero (A Complete Beginner’s
Guide).” YouTube video, 12:40. October 13, 2021.
https://www.youtube.com/watch?v=JG7Uq_JFDzE.

# Point Locator

06:07

# Commentary

This part of the video shows that Zotero is useful for more
than just creating citations. Collections allow sources to
be separated and organized based on a project or topic. This
could make a large research assignment easier because the
sources would not all be mixed together. Organization also
makes it easier to return to information later when writing
or creating additional research notes.

# Keywords

Zotero, collections, research, organization
