# Essay Revision

This folder contains my revised philosophy essay for COMP 250.

## Contents

- `Phil-Paper.md` - The Markdown source file for my revised essay.
- `COMP-250-Essay-Citations.json` - Citation information exported from Zotero.
- `chicago-notes-bibliography.csl` - Citation style used by Pandoc to format the essay in Chicago Notes and Bibliography style.

## Revision Process

For this assignment, I revised my essay to improve the clarity, organization, and flow of my writing.
I revised the introduction and conclusion, improved a body paragraph using principles such as Old Before New and Complexity Last, and made additional changes to unclear sentences throughout the essay.
I also used Zotero and Pandoc to manage my sources and citations.

## Citation Style

The essay uses Chicago Notes and Bibliography style.
Pandoc and the CSL file are used to automatically format the citations and bibliography when the Markdown file is converted to a Word document.
